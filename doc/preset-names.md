# JV-1080 Preset Names and Waveform Lists

Source: Roland JV-1080 Owner's Manual pp. 122–125 ("Default Settings for the Sound Settings / Waveform List" and "Patch Lists"), extracted via OCR from the scanned PDF. The page originals are dense multi-column tables; here each list is re-sequenced by number into a two-column-group layout.

The wave numbers match the Tone WAVE page's Wave Number parameter (INT-A: 1–255, INT-B: 1–193, see [`patch-edit-mode-structure.md`](patch-edit-mode-structure.md)); the patch lists name the factory contents of the USER, PRESET A–C and GM banks (bank addressing per [`jv-1080-midi.md`](jv-1080-midi.md)).
